# VN-2026-08-C1-03 — supabase_admin cross-RLS boundary documentation is load-bearing but easy to violate silently

**Severity:** MEDIUM
**Status:** OPEN (documentation/boundary)
**Location:** `backend/app/core/database.py:1-78`, comment lines 1-39
**Component:** Backend (database access pattern)
**Category:** Trust boundary

## Evidence

The docstring at the top of `database.py` defines a *hard* rule:

> Do not add a new supabase_admin call outside `admin_routes.py` /
> `dsr_routes.py` / `metrics_routes.py` — write a SECURITY DEFINER function
> instead, following that same pattern, and record it in DECISIONS.md.

This rule is enforced only by `tests/test_admin_authz.py` (per the
`ADMIN_ROUTE_MODULES` constant referenced in the docstring) and by
reviewer-discipline. A grep for `supabase_admin` (or any new helper wrapping
it) is not in the regular CI signal.

## Risk

- The "do not add new supabase_admin call sites" rule is enforced by:
  (a) a tests file (only covers those three modules), and
  (b) human review.
- A future developer adding a new "small aggregate" or "one cross-tenant
  lookup" can quietly reintroduce the *exact* exception that DECISIONS.md §29
  and §33 retired. Tests won't catch it if it lives in a new module, and
  reviews miss things.
- Each new admin call site is an unrecorded RLS bypass — the test file says
  "this is the sole access-control boundary on those endpoints" — a small
  forgotten call site in a non-admin module is exactly the kind of bug
  that caused the original retired-exception.

## Recommendation

- Add a `grep`-based CI assertion: every `supabase_admin` reference outside
  `admin_routes.py`/`dsr_routes.py`/`metrics_routes.py` fails CI. (Or, better,
  replace those three modules' references with a single wrapper that *only*
  lives in `admin_routes.py` and re-exports narrow helpers, so the rule
  becomes "no direct `supabase_admin` reference anywhere except that
  wrapper module".)
- Add the rule to `CONTRIBUTING.md` / `AGENTS.md` so it surfaces to future
  agents in their first pass.
